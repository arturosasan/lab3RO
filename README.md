## 🛠️ Instalación de Git

Si aún no tienes **Git** instalado, sigue estos pasos:

### 💻 En Windows

1. Descarga el instalador desde 👉 https://git-scm.com/download/win
2. Ejecuta el archivo descargado.
3. Acepta las opciones por defecto (sirven para la mayoría de los casos).
4. Abre el **Símbolo del sistema (CMD)** o **PowerShell** y escribe:
```bash
git --version
```
   Si aparece un número de versión, ¡ya lo tienes instalado! ✅

### 🐧 En Linux (Debian/Ubuntu)

```bash
sudo apt update
sudo apt install git
```

> Si utilizas otra distribución, lo más seguro es que no necesites que
> te explique como usar Git (I use arch btw).

### 🍎 En macOS

Si tienes Homebrew, simplemente ejecuta:

```bash
brew install git
```

### 📥 Cómo clonar este repositorio

Una vez tengas Git instalado, puedes clonar este repositorio para tenerlo en
tu ordenador:

1. Abre una terminal o consola.
2. Escribe el siguiente comando:

   ```bash
   git clone https://github.com/arturosasan/lab3RO
   ```
3. Entra en la carpeta descargada:

   ```bash
   cd lab2DO
   ```
